# Masked memory operations in library code whose mask is PUBLIC.
#
# instruction_census.py fails on any masked load, store, broadcast or compare
# with a memory operand that no entry here matches: under a secret mask such an
# instruction reads or writes bytes chosen by the secret (src/core/DESIGN.md).
# Permutes with a memory table (vpermb/w/d/q, vpermi2*, vpermt2*) are exempt:
# they are exception class E4NF, with no fault suppression, so the whole table
# is read whatever the mask.
#
# Format:  path | text | why the mask is public   (fields split on " | ")
# `text` must appear on the very source line the census reports, so a new
# masked operation on a neighbouring line needs its own review.  A statement
# split across lines whose line table names another of its lines (either end)
# needs one entry per such line.  Entries match text, not a line number, so an
# entry survives edits elsewhere in the file and stops matching when the line
# itself changes -- which is when it needs a new review.
